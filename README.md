## 📖 Overview

**Al-Ihyahz Press Club** is a specialized digital journalism and institutional news publishing web platform. It delivers an editorial reading experience with content categorization, executive leadership columns, author attribution, and responsive media embeds.

---

## ✨ Features

* **📰 Editorial Article Management:** Modular article structures with rich metadata, category tags, author cards, and reading time estimates.
* **🏛️ Leadership Columns:** Dedicated spotlight sections for executive editorial commentary and institutional press releases.
* **✒️ Author Profiles:** Author bios, profile cards, and publication archives.
* **📱 Responsive Typography:** Optimized typography and grid layouts engineered for readability across mobile, tablet, and desktop viewports.
* **⚡ High-Performance Rendering:** Static generation and fast client hydration powered by Next.js and Tailwind CSS.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router), React
* **Language:** TypeScript
* **Styling:** Tailwind CSS, PostCSS
* **Icons & Assets:** Lucide React Icons

## ⚡ Quickstart

### 1. Clone the repository
```bash
git clone https://github.com/mubarakkasimmaishanu/press-club.git
cd press-club
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the live newsroom in your browser.
